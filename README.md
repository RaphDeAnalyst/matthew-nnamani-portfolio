# Matthew Nnamani — Portfolio

Personal portfolio for Matthew Nnamani, built with React, Vite and Tailwind CSS.

## Local development

```sh
npm install
npm run dev
```

## Build for GitHub Pages

The project is published at `https://raphdeanalyst.github.io/matthew-nnamani-portfolio/`.
Build with the GitHub Actions environment variable so Vite uses the project-site path:

```sh
GITHUB_ACTIONS=true npm run build
```

The `dist/` directory contains the static site.
